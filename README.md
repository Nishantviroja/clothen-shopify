# Clothen Shopify Product Reviews

This repository contains dummy product reviews and aggregated review summaries for the Clothen Shopify store. The generated JSON files act as a mock backend to simulate real customer reviews across various products.

## Overview
- **`review-summary.json`**: Contains aggregated data (`average_rating` and `total_reviews`) for all products.
- **`reviews/`**: A directory containing individual JSON files for each product. Each file includes realistic customer reviews with Indian full names and calculated ratings to match the total summary.
